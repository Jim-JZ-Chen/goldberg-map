# goldberg-map

戈德堡多面体（Goldberg Polyhedron）球形六边形战棋地图原型。单个 `index.html`，浏览器直接打开即玩。

## 功能

- **球面六边形网格**：二十面体细分 + 对偶生成，12 个五边形 + N 个六边形，欧拉公式实时验证
- **三种细分方式对比**：弦投影 / 球面弧细分（slerp）/ 等面积松弛（Snyder 思路的梯度下降数值实现），实时显示六边形面积均匀度
- **柏林噪声地形**：海洋 / 陆地 / 森林 / 山脉，可播种 fbm，一键换地图
- **领地系统**：连通分量 + 最远点采样选首都，多源 BFS 划分势力范围，文明式彩色双边带边界
- **寻路演示**：点击格子选起点终点，A* 沿陆地绕行，悬停高亮、邻居展示

## 运行

直接用浏览器打开 `index.html`，或任意静态服务器托管。three.js 从 jsDelivr CDN 加载（0.160.0 固定版本）。

## 操作

- 拖动旋转，滚轮缩放
- 细分频率 m：1（正十二面体）~ 10（1002 格）
- 地图模式下点两个陆地格子看 A* 寻路
